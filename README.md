98 characters. Behind the line: the first payout on make.fun ever (a passport poem, 89.29%, $3 paid 2026-11-21), a GTA6 entry at 99.01% that missed the prize line by a third of a point, a forecast entry inside the top ten, and a Javanese prince crowned on YouTube in Diponegoro Season 2 Episode 1.

## Run it

```sh
node main.ts
```

It writes the line to `${OUTPUT_DIR:-/output}/entry.txt` (default `/output`). Point it somewhere else with `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/out-week-one-line node main.ts
```

Needs Node 22.18 or later (TypeScript runs as-is, nothing to install).
